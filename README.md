## Por que este projeto?
Este projeto foi desenvolvido com o objetivo de automatizar os principais fluxos funcionais da aplicação Sauce Demo utilizando Cypress e JavaScript. Os cenários automatizados foram definidos a partir do plano de testes manual desenvolvido anteriormente no projeto "plano-de-testes-sauce-demo", demonstrando a evolução do processo de testes desde o planejamento manual até a implementação da automação E2E.
