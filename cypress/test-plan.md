# Plano de Testes Automatizados

## Objetivo da automação

Automatizar os principais fluxos funcionais da aplicação Sauce Demo utilizando Cypress.

## Funcionalidades automatizadas

- Login;
- Produtos;
- Carrinho;
- Checkout;
- Logout;
- Ordenação dos produtos.

## Estratégia dos testes

- Testes positivos;
- Testes negativos;
- Testes funcionais;
- Testes E2E.

## Critério de aprovação

- Todos os cenários automatizados devem ser executados com sucesso.

## Critério de encerramento

- Todos os cenários implementados;
- Documentação concluída;
- Testes executados com sucesso.
